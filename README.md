# Skin Clock

A movable analog clock for GNOME Shell with selectable skins and configurable appearance.

## Features

- Analog clock with hour, minute and second hands
- Multiple built-in skins
- Drag the clock with the left mouse button
- Resize with the mouse wheel
- Adjustable opacity
- Optional second hand
- Smooth second-hand movement
- Configurable refresh rate
- Show/hide from the GNOME top panel
- Reset position from the panel menu
- Right-click the clock to open preferences

## Built-in skins

- Classic
- Railway
- Minimal
- Neon
- Graphite

## Installation

Install:
gnome-extensions install --force skin-clock@arnoxar-du-24.zip

Enable:
gnome-extensions enable skin-clock@arnoxar-du-24

Preferences:
gnome-extensions prefs skin-clock@arnoxar-du-24
